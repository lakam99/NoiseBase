NOISEBASE FOR APPLE SILICON
Native arm64 standalone application and VST3 effect. Supports M-series Macs
(M1, M2 and later), running macOS 14 Sonoma or later. Rosetta is not required.
Use an Apple Silicon/native DAW to load this arm64 VST3. No Intel build or AU
component is included.

INSTALL
1. Extract NoiseBase-VERSION-macOS-arm64.zip.
2. Copy NoiseBase.app into Applications (or your own ~/Applications folder).
3. For VST3 use, copy the entire NoiseBase.vst3 bundle into:
   ~/Library/Audio/Plug-Ins/VST3/
   Finder > Go > Go to Folder can open that location. Create VST3 if needed.
4. Restart/rescan your DAW. Keep the complete bundles intact; each contains its
   speech-detector runtime, model and generated artwork. Do not copy only the
   inner executable. Close the app/DAW before replacing an older version.

This initial Mac distribution is ad-hoc signed, not Developer ID signed or
Apple-notarized. macOS may block a downloaded copy. Apple's supported approval
process and security explanation are here:
https://support.apple.com/en-us/102445
No system-wide Gatekeeper changes or quarantine-removal commands are required.

USE
LOAD CLIP automatically scans the whole recording and maps different quiet
backgrounds across stitched clips. AUTO follows those local floors in standalone
preview and file export. LEARN re-analyzes the entire loaded file; HOLD freezes
the active floor. Without a file, the VST3 learns incoming DAW audio automatically
and LEARN restarts that analysis. It cannot read unplayed host audio.
CLEAN previews
or exports denoised dialogue. NOISE BASE + REMOVED monitors the removed-noise
estimate, which can include dialogue bleed. NOISE BASE + PROCEDURAL generates
fresh ambience indefinitely from quiet-section statistics. Press play in the
standalone app; the VST3 follows the host's processing clock.

The procedural profile is saved with standalone settings/DAW state and works
without reopening the reference. PRINT WAV defaults to a 60-second seamless
procedural loop, with an editable duration of 1 to 3600 seconds. MIX controls
its level and OUTPUT TRIM sets gain. BYPASS restores the original input.

The profile stores statistical spectra, stereo correlation and level variation,
not recorded speech snippets. At least 0.35 seconds of confidently detected quiet
background is required. It generates a background texture, not individual birds,
vehicles or impacts. Audition the result: voice detection can misclassify audio.

UPDATES checks GitHub Releases; installing Mac updates is manual through the
release download page. No audio is uploaded. Audio processing needs no account,
network connection or API key. Windows' PowerShell installer is not used on Mac.

SAVED LIVE PROFILE CACHE
Save your DAW song after learning. Each NoiseBase instance stores its live CLEAN
floor and sidechain cache in the plug-in state inside that song. Reopening the
saved song restores those profiles with AUTO still enabled. AUTO recalls known
timeline regions and keeps adapting to new or changed backgrounds. LEARN clears
the selected source's cache and rebuilds it as audio arrives; with a loaded file,
it still rescans the entire file. A VST3 cannot analyze unplayed host audio.

Up to 64 regions per source contain statistical spectra and ambience properties,
not recorded audio. No external cache file or recording edits are required.
NoiseBase tells the host when learned state changes so it can save that state.
The VFD shows the cached-region count. Moving/replacing clips can need new
learning at their new timeline positions. Cached sidechain profiles still obey
playback/input gating and the BRIDGE delay when enabled.

VST3 SIDECHAIN REFERENCE
Put NoiseBase on an ambience track/bus that your DAW keeps processing. Enable
its Reference sidechain in the DAW and send another track to that input. Select
REFERENCE: SIDECHAIN, NOISE BASE, PROCEDURAL and AUTO. Play a passage containing
quiet background. The VFD reports learning/readiness; MIX and OUTPUT set level.
AUTO follows background changes, HOLD freezes the texture, and LEARN resets it.
The reference is analyzed on a worker; it is never mixed directly into output.
The main input remains the source for CLEAN/REMOVED and bypass.

Generation follows host playback and reference activity. Stop, a disconnected
send or digital silence fades output out; incoming reference during playback
resumes it. HOLD freezes texture while following input/transport. AUTO seeks or
loop wraps recall cached destinations; unknown regions wait for fresh quiet
background. HOLD keeps its model. Saved state retains the profile cache, but
also waits for reference.
The input meter/numeric VFD level show the sidechain; host position/play/stop
appear when supplied. Offline rendering follows actual reference input, and
hosts without transport information use input activity. CLIP remains continuous.
Select BRIDGE to keep the preceding background through short gaps when another
clip is visible ahead. GAP TIME sets the maximum gap (0.05-2 seconds, default
0.75). The next profile transitions at that clip's buffered position; longer
gaps and the end of supplied audio fade out. HOLD keeps its fixed texture.
BRIDGE adds two seconds of latency reported to the DAW for compensation; the
gap slider does not change latency. Disable BRIDGE to restore normal latency.
Only the selected future window is examined. The input meter leads buffered
output, and new profiles still need confidently quiet reference material.
PRINT WAV can export the active
sidechain model as a 60-second seamless loop. CLIP selects the loaded-file source;
LOAD CLIP switches to it automatically. The standalone uses loaded clips.
Learning is causal, speech detection can misclassify audio, and synthesis creates
a statistical texture rather than reproducing individual events. Audition it.
