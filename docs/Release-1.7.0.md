NoiseBase 1.7.0 can learn another DAW track through a VST3 sidechain and generate fresh matching ambience on its main output.

- Enable the Reference sidechain in the DAW, send the reference track to it, then select REFERENCE: SIDECHAIN, NOISE BASE, PROCEDURAL and AUTO. Mono and stereo references work with mono or stereo main buses. CLIP uses the existing loaded-file workflow; existing sessions default to CLIP.
- Speech detection and spectral/stereo analysis run on a separate worker with a bounded queue. The analysis waits for speech decisions on both sides of each window. Neither neural inference nor worker teardown waits indefinitely in the audio callback. A stalled worker leaves the last usable model generating; slow cleanup uses the existing safe retirement mechanism.
- AUTO follows stable reference-background changes; HOLD freezes the active generator profile. LEARN resets sidechain learning. Silence/stopped input preserves the last model. Source selection and the active compact statistical model are saved in DAW state, including HOLD behavior, and restore without the reference track. PRINT WAV can export that model as a 60-second seamless loop.
- The reference signal is never mixed directly into the main output. CLEAN, REMOVED and bypass retain their main-input routing. Procedural output reports an infinite tail; hosts still need to process the effect rather than suspend it. The new switch uses the existing generated raster hardware artwork, with changing source/status text in the VFD.

Validation covers stereo level matching and mono/stereo bus layouts, spectral/background changes, speech over an unchanged noise floor using a locally synthesized phrase, exact HOLD model retention, continued output with silent/disconnected reference, saved-state restoration, main/sidechain isolation, and delayed reference-worker cleanup. The existing full-file, transport/export, procedural loop and repeated VST3 removal checks also run. Native reports and actual UI previews are included in the platform packages.

Sidechain learning is causal: it cannot inspect future or unplayed DAW audio. It needs confidently quiet background and uses a short analysis look-ahead; this does not delay the reference into the main output. Detection can misclassify material. Synthesis matches a statistical texture rather than individual events or voices. Standalone keeps its loaded-file reference workflow. The earlier Studio Pro freeze remains unconfirmed in that DAW; native stress-host results are not DAW certification.
