NoiseBase 1.8.0 fixes sidechain timeline following and metering, and adds optional lookahead gap bridging.

- FOLLOW gates sidechain procedural output with host play/record and actual reference activity. Host stop, disconnected input and digital silence fade out; reference audio returning resumes output. AUTO seeks and loop wraps discard old-location analysis, including host reinitialization. HOLD keeps its texture while following playback. Restored models wait for input. Offline rendering accepts reference audio even with a stopped live-transport flag, and absent transport information falls back to input activity.
- BRIDGE buffers two seconds, reported as additional latency to the DAW. GAP TIME sets the maximum bridged gap from 0.05 to 2 seconds (default 0.75) without changing latency. If another clip is visible within that window, the previous ambience continues through the gap. Longer gaps and the end of supplied audio fade out. No bed starts before the first clip or re-enters early during a longer gap. The next learned profile is scheduled at its buffered source position, with a smooth spectral transition. Disabling BRIDGE restores normal latency. Latency notifications run outside the audio callback; all playback buffers and profile-history slots are preallocated and bounded.
- The input meter reads the selected sidechain, including either stereo channel. The VFD adds numeric input dBFS, gap duration/status, and host position/play/stop. The new switch and small slider reuse generated raster hardware artwork. CLIP generation, seamless WAV export and main-input CLEAN/REMOVED/bypass routing remain available.

Processor and real VST3-host checks cover transport, gaps/resume, AUTO seeks/loops, host reinitialization, HOLD, saved/disconnected/reconnected profiles, offline rendering and input isolation. Lookahead tests use two clips with different background levels and verify bridging versus a smaller gap limit, transition timing, silence before the first/after the last clip, and reported/restored latency. Existing denoising, full-track, worker cleanup, file/export and skin checks also run. Native reports are included in the packages. The exact Studio Pro session has not been automatically exercised.

Lookahead can inspect only its received window, not unseen future clips anywhere in the arrangement. New profiles need confidently quiet reference; voice detection can misclassify material. The meter shows incoming reference, which leads the buffered output when BRIDGE is enabled. Hosts may resynchronize when its compensated latency changes. Synthesis produces statistical texture rather than individual events or voices.
