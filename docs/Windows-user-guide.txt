NOISEBASE 1.5.1 - WINDOWS x64
Automatic dialogue denoising, with an analog hardware-style interface.

IN THIS PACKAGE
  Standalone/NoiseBase.exe          Native application
  VST3/NoiseBase.vst3/              Complete VST3 effect bundle
  Previews/                        Actual native interface renders
  Artwork/                         Generated PNG assets and exact prompts
  NoiseBase-source.zip             Complete build source and dependencies
  Licenses/                        Open-source and third-party notices

The application and plug-in do not require Python, an account, an API key, or
an audio upload. The included neural detector runs locally on the CPU. Keep
onnxruntime.dll and onnxruntime_providers_shared.dll with the application and
inside the VST3 bundle; do not copy only the inner VST3 DLL.

GENERATED RASTER ARTWORK
Ivory, Graphite and Walnut faceplates, knobs, meter housings, switch states,
button states and lamps use generated PNG artwork embedded in both builds.
Live labels, calibration marks, needles and knob pointers remain native
controls. No SVG artwork is used for the interface. Original PNGs and exact
generation prompts are included in Artwork and in the source archive.
Existing parameter identifiers are preserved; new controls are appended.

STANDALONE
The cyan vacuum fluorescent display contains all changing faceplate text:
control values, selected skin, tape status, progress, filename, and time.
Long filename/status lines scroll inside the display.

Transport icons: play triangle toggles to pause bars while playing; stop square
stops and rewinds; bar with left triangles returns to zero without changing
play/pause; repeat arrows toggle looping. Loop mode shows a green jewel and
LOOP ON in the VFD. Turning loop off finishes the current pass. Loop affects
preview only; clean/removed PRINT WAV exports the source recording once. Loop mode
is remembered between standalone launches.

1. Run Standalone/NoiseBase.exe.
2. LOAD CLIP, or drop a recording onto the faceplate. The app scans it
   automatically for speech-free sections and builds a noise profile.
3. When PROFILE READY appears, press the play triangle. Use BYPASS for a level-aware comparison.
4. Adjust REDUCTION, VOICE DETAIL, DRY/CLEAN and OUTPUT TRIM.
5. PRINT WAV saves a denoised copy. The source cannot be overwritten.

Exports preserve sample count, sample rate and mono/stereo layout. Supported
integer/float WAV bit depth and supported WAV metadata are carried through.
The offline renderer compensates its own processing latency. Compressed inputs
are decoded and exported as WAV, not rewritten into the compressed container.
PATCH BAY opens the audio-device settings. The default device setup uses no
microphone inputs, so the file workflow does not require input monitoring.

INSTALLATION AND UPDATES
Run Install-NoiseBase.ps1 from the extracted NoiseBase folder. This installs
both the standalone app and the complete VST3 for your user account, creates
Start menu and Installed Apps entries, and preserves user settings.

Application: %LOCALAPPDATA%\Programs\NoiseBase
VST3: %LOCALAPPDATA%\Programs\Common\VST3\NoiseBase.vst3

Rescan plug-ins in your DAW. Add the VST3 parent folder to its search locations
if necessary. The installer verifies the release payload, protects unowned
directories, refuses downgrades/in-use files, and rolls back failed file swaps.
Close NoiseBase and DAWs using the VST3 before manually upgrading.

The standalone app checks GitHub Releases on startup, at most once daily after
a successful check. UPDATES offers a manual check and an automatic-check toggle.
New stable versions offer Download update, then Install and restart. Packages
must match GitHub's asset SHA-256 digest, SHA256SUMS.txt and per-file payload
hashes. HTTPS and repository security establish trust; releases are not
Authenticode-signed. No audio is sent to GitHub. The VST3 itself never checks
for updates or replaces a module inside a running DAW. The previous installed
version is retained as a backup; user settings and recordings are preserved.

PROCEDURAL AMBIENCE FROM ONE CLIP
LOAD CLIP works in the VST3 and standalone. Select NOISE BASE and PROCEDURAL
after the scan to generate fresh continuous ambience from quiet-frame spectra,
channel energy, stereo correlation and gentle level variation. It continues
beyond the clip length and with silent host input. The host must keep processing
the VST3; suspension/stopped processing also stops generation.

The model stores aggregate statistics, not recorded waveform or speech snippets.
It is saved with DAW sessions and standalone preferences, and works without the
source file after restore. At least 0.35 seconds of confidently quiet background
is required; an uncertain estimated floor cannot drive synthesis. Detection may
misclassify material: audition the result. Distinct birds, vehicles, impacts and
other recognizable events are not recreated by this statistical ambience bed.

Play/pause controls standalone generation; stop resets elapsed time. The VFD
shows INF; the recording-loop button is disabled because generation is already
continuous. PRINT WAV defaults to a 60-second seamless loop; duration is editable
from 1 to 3600 seconds. Rate and mono/stereo layout follow the reference. MIX is
generated level, OUTPUT TRIM sets gain. Reduction and voice detail are denoiser
controls. BYPASS restores the original. Existing sessions keep REMOVED routing
until PROCEDURAL is explicitly selected.

REMOVED-NOISE MONITORING AND NOISE-BASE EXPORT
The NOISE BASE / CLEAN switch selects the processed output in both formats.
NOISE BASE with REMOVED outputs the component removed by the denoiser. In a VST3 this plays
through the host track in real time; in standalone it affects both preview and
PRINT WAV. The VFD reports the active output. The export dialog offers
NoiseBase-noise-base.wav by default when noise-only is active.

This is an estimated removed-noise stem. Speech may bleed into it where speech
and noise overlap. Select PROCEDURAL for synthesized ambience instead. Learn a quiet
floor in AUTO before evaluating it; use HOLD to freeze a reliable profile.
VOICE DETAIL helps prevent speech from being removed. MIX scales the removed
component. Zero MIX or zero REDUCTION gives silence in noise-only mode.
BYPASS restores the original, including dialogue, and ignores OUTPUT TRIM.

WINDOW APPEARANCE
The standalone window and JUCE utility dialogs follow Windows app light/dark
mode; native title-bar changes are applied while running. Hardware faceplate
selection remains manual. A generated cyan/glass application icon is embedded
in the Windows executable and used by the window and Start menu installation.
The DAW controls the outer frame of a hosted VST3 editor.

LIVE OPERATION
Insert NoiseBase on a dialogue channel. Leave AUTO selected while playing
material that includes a short pause; the floor indicator turns green once
enough noise has been learned. Select HOLD to keep the profile fixed. LEARN
resets it and selects AUTO again. Noise learning is intentionally conservative
during speech. Until a reliable floor is available, reduction is capped at
6 dB. The stand-alone file scanner can look across the whole recording before
processing; a conventional VST3 only receives the audio played through it.

CONTROLS
  REDUCTION       Maximum suppression, 0-24 dB. Start around 10-14 dB.
  VOICE DETAIL    More protection for quieter speech components.
  DRY / CLEAN     Blend original and denoised audio at matching latency.
  OUTPUT TRIM     -12 to +12 dB; true bypass ignores this trim.
  AUTO / HOLD     Adapt from non-speech, or freeze the current noise floor.
  LEARN           Clear and relearn the floor.
  BYPASS / IN     Switch between unchanged and processed audio.
  FACEPLATE       Three-position skin selector. No change to audio character.

The needles show peak level in dBFS and average spectral gain reduction in dB;
they are hardware-style displays, not certified VU loudness meters. Current
knob values appear while dragging, and all main controls support host automation.
Control positions and the skin are saved with the DAW state. The stand-alone
also remembers controls between launches. Live noise profiles are relearned
when a new audio session starts; use a short pause before committing a bounce.

LATENCY AND LIMITS
Latency is reported to the host: 2048 samples at 44.1/48 kHz, 4096 at 96 kHz
(about 43-46 ms). File export removes this delay. Bypass and dry blend remain
aligned. This is intended for dialogue and persistent background noise; it
does not reliably isolate overlapping speakers, fix clipping, or remove every
wind/handling impact. Excessive reduction may soften consonants or sound watery.
Use a lower REDUCTION setting when necessary and audition the full scene.
